# Temporary Media & Fallback Data

This folder contains temporary placeholder photos and media used for the gallery before your own photos are added in Sanity CMS.

### How to use your own photos:
1. Open Sanity Studio (`/sanity` or run `cd sanity && npm run dev`).
2. Add new **Gallery Item** documents with your images or videos.
3. The gallery will automatically fetch and display your uploaded photos from Sanity.
4. Once you have uploaded your items in Sanity, you can delete this `src/remove/` folder.
